# How the game works 

The game has only two players, one turn, and three cards: King > Queen > Jack

1. Players put in 1 chip into the pot each
2. The first player (p0) can then either choose to check or bet 
    - if p0 checks -> p1 can check or bet 
    - if p0 bets -> p1 must bet or fold 
3. Once players have made their move, the cards are revealed
